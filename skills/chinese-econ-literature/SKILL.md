# 中文经管文献综述与理论机制

把“逐篇介绍文献”改写成围绕研究问题的证据综合。优先读取本地 Zotero 的题录、摘要、全文和标签；用 `Awesome-Journal-Skills` 的范本目录辅助按方法、选题和期刊定位，但回到原文核对具体结论。

## 工作步骤

1. 将文献按问题、机制、识别方法或结论分组，而不是按作者逐篇罗列。
2. 每组先概括共识，再指出分歧、适用条件和证据不足。
3. 明确本文与已有研究的关系：延伸对象、改进测量、更新识别、补充机制或检验边界。
4. 理论机制必须导出可观察预测，再连接到变量、回归或异质性检验。
5. 只在原文支持时写“发现”“证明”；对摘要、工作论文和二手来源使用较弱措辞。

## 推荐段落

研究主题 → 文献共识 → 解释分歧 → 现有不足 → 本文切口 → 可检验假说。

避免“国内外学者进行了大量研究”“填补空白”等无具体内容的句子。详细矩阵见 [references/literature-matrix.md](references/literature-matrix.md)。
