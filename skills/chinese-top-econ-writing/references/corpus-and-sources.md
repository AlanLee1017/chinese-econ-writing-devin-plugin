# 语料选择与来源核验

## 推荐来源

1. 用户本地 Zotero：优先读取条目的作者、年份、期刊、摘要、全文附件和 `extra` 字段。
2. 原刊官网、作者主页、机构仓储：核对题名、卷期、页码、摘要和文章归属。
3. `Awesome-Journal-Skills`：作为《经济研究》范本目录、识别方法和热点选题的发现入口。该仓库明确要求对期刊归属和具体结论回到原文核验。
4. 其他 GitHub 资源：可用于发现 CSL 样式、写作提示和题录数据集，但不能把提示词或题录数据集当作原文证据。

## 样本选择

优先组合：

- 至少两种研究领域；
- 至少三位作者或作者团队；
- 至少两种识别方法；
- 同时包含高被引老文章和近年文章；
- 至少一篇摘要之外有可读全文的文章。

## 记录字段

每篇文章至少记录：作者、标题、期刊、年份、卷期、页码、DOI或稳定URL、Zotero key、全文可得性、引用数及日期、研究领域、识别方法、可学习的段落功能。

## 不能直接推出的结论

- 被引数高不等于写作质量高，也不等于识别策略无争议。
- 摘要结构不等于全文结构。
- 同一期刊中的理论、结构估计、准实验和案例研究不能用同一套句式评价。
- 作者风格应概括为可观察的论证和句法模式，不应归结为个人标签或固定“口吻”。
