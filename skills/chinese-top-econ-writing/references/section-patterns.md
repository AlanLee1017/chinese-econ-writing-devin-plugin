# 分部分写作范式

以下是从本地 Zotero 样本和《Awesome-Journal-Skills》范本目录中归纳的结构。它们是分析框架，不是固定套话。

## 1. 引言

### 基本段落顺序

1. 现实现象、制度变化或经济问题。
2. 已有研究回答了什么，仍留下哪一个可检验问题。
3. 本文用什么制度变化、数据或识别设计回答该问题。
4. 主要发现，按主结果、机制、异质性或边界条件排序。
5. 相对于已有文献的具体增量。

### 句子结构

- “近年来，……成为……中的重要现象，但……之间的关系仍缺乏一致证据。”
- “已有研究主要从……解释……，较少关注……。”
- “本文利用……带来的外生变化，考察……对……的影响。”
- “结果表明，……；进一步分析发现，……。”
- “本文的边际贡献在于……，其前提是……。”

### 约束

引言中的“首次”“填补空白”“证明”需要有可核验的文献和设计依据；贡献应落到问题、数据、识别或机制中的具体一项。

## 2. 制度背景与研究假说

### 基本顺序

制度事实 → 行为主体的激励 → 可观察预测 → 经验检验。

### 句子结构

- “该制度调整改变了……的约束条件。”
- “在……激励下，地方政府/企业可能通过……调整……。”
- “如果上述机制成立，则……应在……样本中表现得更明显。”

### 约束

把制度事实、理论推论和经验发现分开写。制度背景不能代替识别假设。

## 3. 数据与变量

### 基本顺序

数据来源与样本 → 观测单位和时间范围 → 核心解释变量与被解释变量 → 控制变量 → 描述性统计与样本特征。

### 句子结构

- “本文使用……数据库，样本覆盖……至……。”
- “本文将……定义为……，其构造依据是……。”
- “为避免……造成的测量偏误，本文剔除……。”
- “表1报告了主要变量的描述性统计，……的均值为……，表明……。”

### 约束

不要把数据来源写成数据质量判断；不要把变量相关性写成机制证据。

## 4. 识别策略与模型

### 基本顺序

估计目标 → 处理变量和对照 → 变化来源 → 关键假设 → 固定效应与标准误 → 威胁与检验。

### 句子结构

- “本文利用……的时间/空间差异识别……的影响。”
- “该设计的识别依赖于……在政策实施前具有相似趋势。”
- “模型控制了……固定效应，标准误聚类于……层级。”
- “该做法能够缓解……，但无法排除……，因此本文进一步进行……检验。”

### 约束

“解决内生性”“证明因果关系”只在假设和检验足够时使用；多数场合用“缓解内生性担忧”“提供因果识别的证据”。

## 5. 基准实证结果

### 推荐结果顺序

方向 → 量级 → 统计不确定性 → 经济含义 → 表格定位。

### 句子结构

- “表2列（1）显示，……的估计系数为……，在……水平上显著。”
- “从经济量级看，……相当于……的……%。”
- “该结果表明……，与……假说一致。”
- “加入……控制变量后，系数的符号和量级保持稳定。”

### 约束

不要只写“显著为正”；不要把统计显著等同于经济重要；不要把“与假说一致”写成“验证了机制”。

## 6. 机制分析

### 推荐顺序

机制命题 → 可观测预测 → 检验结果 → 机制边界。

### 句子结构

- “前文结果可能通过……实现。若该解释成立，则……应当发生变化。”
- “表4显示，……在……样本中的变化更明显，说明……可能是重要渠道。”
- “这一结果支持……的解释，但不能单独排除……。”

### 约束

中介回归、交互项或异质性结果通常是支持性证据，不自动等于机制被证明。

## 7. 异质性与边界条件

### 推荐维度

主体特征、制度环境、市场化程度、信息环境、时间阶段、行业或地区。

### 句子结构

- “该效应主要集中于……，而在……中并不显著。”
- “这一差异与……机制相符，表明……可能构成重要边界条件。”
- “异质性结果说明，政策效果取决于……，而非政策工具本身。”

## 8. 稳健性与替代解释

### 按威胁分类

- 测量：替代变量、不同口径。
- 样本：缩尾、剔除特殊地区/年份、平衡面板。
- 设定：固定效应、趋势项、权重、函数形式。
- 推断：聚类层级、随机化推断、空间相关。
- 时序：预趋势、安慰剂、提前期/滞后期。
- 替代解释：控制同期政策、排除其他渠道、伪处理组。

### 句子结构

- “为排除……，本文进一步……。”
- “在采用……后，核心系数仍保持……，表明结果并非由……驱动。”
- “该检验针对的是……威胁，并不直接检验……。”

## 9. 结论与政策含义

### 基本顺序

核心发现 → 机制或边界 → 研究含义 → 可执行政策。

### 句子结构

- “本文发现……，该效应主要通过……实现，并在……条件下更为明显。”
- “上述结果表明，……政策需要同时关注……。”
- “对政策而言，……比单纯扩大……更为关键。”

### 约束

政策建议必须能追溯到估计结果和制度环境；避免从单一地区、单一时期或单一政策试点外推到所有情形。

## 10. 跨领域风格差异

- 宏观与基础设施：重视历史阶段、总量结果和制度背景。
- 公共财政与地方治理：重视权责关系、政策冲击、政府激励和边界条件。
- 金融与公司金融：重视资产负债表、风险承担、信息网络和市场后果。
- 数字经济与平台：重视理论渠道、替代解释、成本下降和多重异质性。
- 劳动与福利：重视分布效应、选择性偏误、分解方法和政策覆盖范围。

## 11. 可迁移句法的使用规则

模板只能承载用户已有的变量、估计结果和识别设计。使用前替换所有占位符，并检查：

- 主语是否是研究对象而不是抽象的“本文”；
- 因果动词是否得到识别策略支持；
- 是否报告了量级而不是只报告显著性；
- 是否说明表格、样本、时间范围和统计推断；
- 是否把机制、异质性和稳健性区分开。
