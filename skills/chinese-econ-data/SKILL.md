# 中文经管制度背景与数据变量

将制度事实、样本构造和变量定义写成可复核的研究设计基础。制度背景只解释政策时间、处理分配、行为激励或机制所需的信息；数据部分说明来源、单位、范围、清洗和测量。

## 制度背景

按“制度安排 → 改革变化 → 受影响主体 → 可利用变异 → 研究问题”组织。区分原始制度事实、作者解释和经验结果，避免用政策宣传替代制度分析。

## 数据与样本

按“来源 → 时间和空间范围 → 观测单位 → 样本筛选 → 缺失和异常处理 → 最终样本”叙述。变量先给操作性定义，再说明经济含义。描述性统计报告分布和样本特征，不提前宣布因果结论。

没有输入支撑时，不补写样本量、数据库版本、清洗比例、变量均值或政策日期；应明确标记为待补信息。

## 推荐句式

- “本文使用……数据库，样本覆盖……。”
- “本文将……定义为……，并依据……进行构造。”
- “为保证……，本文剔除……，最终得到……个观测值。”
- “表1显示，……的均值/中位数为……，表明样本具有……特征。”
